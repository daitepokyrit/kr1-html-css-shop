## Структура страниц (5 обязательных страниц)
- `index.html` — главная страница: hero-блок, преимущества, сетка популярных товаров, модальное окно заявки;
- `catalog.html` — каталог товаров со статическим блоком фильтров и сеткой товаров;
- `product.html` — детальная карточка товара, бейдж и таблица характеристик;
- `order.html` — отдельная страница оформления заказа с валидацией полей;
- `contacts.html` — контактная информация, адрес и обратная связь;
- `css/style.css` — единый внешний файл стилей;
- `js/main.js` — скрипт управления модальным окном и валидацией;
- `README.md` — документация проекта;
- `.gitignore` — список файлов, исключённых из Git.

## Используемые технологии и архитектура
1. **Семантическая разметка:** `header`, `nav`, `main`, `section`, `article`, `aside`, `footer`, `dialog`, `table` (`caption`, `thead`, `tbody`, `th`, `td`).
2. **CSS-архитектура:**
   - Переменные токенов в `:root` (цвета, отступы, скругления);
   - Состояния элементов: `:hover`, `:focus-visible`, `:disabled`, `:target`;
   - Сброс блочной модели через `box-sizing: border-box`.
3. **Flexbox и CSS Grid:**
   - Flexbox для меню навигации, шапки и вертикального выравнивания карточек (`margin-top: auto`);
   - CSS Grid для сетки товаров (`repeat(3, 1fr)`) и страницы каталога (`260px 1fr`).
4. **БЭМ-именование:**
   - Блоки: `site-header`, `site-nav`, `breadcrumbs`, `hero`, `products-grid`, `product-card`, `catalog-layout`, `catalog-filters`, `order-dialog`, `order-form`, `button`, `site-footer`;
   - Элементы: `product-card__title`, `product-card__price`, `product-card__badge`, `site-nav__link`;
   - Модификаторы: `product-card--featured`, `product-card--discount`, `site-nav__link--active`, `button--primary`.
5. **Позиционирование:**
   - `position: relative` (контейнер карточки товара);
   - `position: absolute` (бейдж «Хит» / «Скидка»);
   - `position: sticky` (липкий сайдбар фильтров в каталоге);
   - `position: fixed` и `z-index` (плавающая кнопка «Наверх»).
