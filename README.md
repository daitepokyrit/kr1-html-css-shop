# Контрольная работа №1. Учебный frontend-проект
## Описание
Проект представляет собой многостраничный сайт интернет-магазина, разработанный в рамках дисциплины «Фронтенд и бэкенд разработка».

## Структура страниц (5 обязательных страниц)
- `index.html` — главная страница: hero-блок, преимущества, сетка популярных товаров, модальное окно заявки;
- `catalog.html` — расширенный каталог товаров (6 позиций) со sticky-панелью фильтров;
- `product.html` — детальная карточка товара и расширенная таблица характеристик и тарифов;
- `order.html` — отдельная страница оформления заказа с полями валидации;
- `contacts.html` — контактная информация, адрес и форма связи;
- `css/style.css` — стили проекта по БЭМ;
- `js/main.js` — управление модальным окном и звуковой эффект клика на Web Audio API.

## Самостоятельные доработки для повышения оценки
1. **Для Практической работы №8:**
   - **Фиксированная кнопка «Наверх»:** круглая плавающая кнопка (`position: fixed; z-index: 100`) с плавным скроллом к началу страницы (`#top`).
   - **Sticky-фильтр каталога:** боковая колонка фильтров зафиксирована через `position: sticky; top: 20px` и не уходит из зоны видимости при скролле товаров.
   - **Несколько вариантов карточек через БЭМ-модификаторы:** реализованы модификаторы `.product-card--featured`, `.product-card--discount`, а также цветовые бейджи статуса `.product-card__badge--hit`, `.product-card__badge--new`, `.product-card__badge--discount`.
   - **Дополнительные состояния кнопок и карточек со звуковым эффектом:** карточки плавно приподнимаются при наведении (`transform: translateY(-4px)`), кнопки имеют состояния `:hover`, `:active`, `:focus-visible`, а при клике воспроизводится мягкий щелчок через Web Audio API.

2. **Для Контрольной работы №1:**
   - **Дополнительные страницы:** развернута полная пятистраничная структура сайта с единым навигационным меню.
   - **Более подробная карточка товара:** на странице `product.html` детально описан товар с кнопками быстрого перехода к оформлению заказа.
   - **Расширенная таблица характеристик и сравнения тарифов:** добавлена таблица на странице `product.html` со стилизацией через `caption`, `thead`, `tbody`, `:nth-child(even)` и подсветкой строк при наведении.
   - **Расширенный каталог товаров:** страница `catalog.html` содержит 6 карточек товаров различных категорий и ценовых диапазонов.
